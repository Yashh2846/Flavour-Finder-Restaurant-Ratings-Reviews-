# Flavour Finder: Restaurant Ratings & Reviews

Flavour Finder is a mini-project web application for exploring restaurants by city and viewing restaurant details, menus, ratings, and reviews.

## Technologies
- HTML
- CSS
- JavaScript

## Project report
The original 87-page mini-project report describes the project, its modules, technical stack, sample code, and screenshots.

## Source code status
The report contains code samples, but the original standalone source files and local image assets were not included with the uploaded PDF. The code should be recovered from the original project folder before treating this repository as a runnable version.

## How to run
Once the original project files are added, open `index.html` in a browser. Keep the HTML files and their referenced local assets in the expected folder structure.
